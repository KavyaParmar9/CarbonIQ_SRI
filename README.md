# CarbonIQ

Modern sustainability analytics platform for industrial carbon emissions.

## Tech stack
- React
- TypeScript
- TailwindCSS
- Recharts
- Framer Motion

## Scripts
- `npm install`
- `npm run dev`
- `npm run build`
- `npm run preview`

## Structure
- `src/App.tsx` - main layout and page navigation
- `src/pages` - Home, Analysis Dashboard, Carbon Calculator, CBAM Research, About
- `src/components` - shared UI components
- `src/data` - chart data and calculator models
